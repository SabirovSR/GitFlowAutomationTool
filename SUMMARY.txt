🚀 КАК НАЧАТЬ:
   1. Запустите:  ./install.sh
   2. Перезапустите терминал или: source ~/.bashrc
   3. Проверьте:  git flow help
   4. Читайте:    QUICKSTART.md
   5. Используйте: git flow

   4. ARCHITECTURE.md    (опционально) - для разработчиков

💡 ТИПИЧНЫЕ КОМАНДЫ:
   git flow              # Открыть меню
   git flow deliver      # Доставить изменения
   git flow hotfix       # Создать hotfix
   git flow continue     # Продолжить после конфликта
   git flow help         # Справка

🎯 ПОДДЕРЖИВАЕМЫЕ СЦЕНАРИИ:
   • Стандартная доставка в test
