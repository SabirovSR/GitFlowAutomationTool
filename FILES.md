# 📂 Описание файлов проекта

## Исполняемые скрипты (Executable Scripts)

### git-flow (9.0K)
**Назначение:** Главный скрипт с интерактивным меню  
**Как использовать:** `git flow` или `git flow <command>`  
**Функции:**
- Интерактивное меню с автоопределением доступных команд
- Маршрутизация на подкоманды (deliver, hotfix, continue)
- Создание новых feature и hotfix веток
- Отображение статуса операций
- Справочная информация

---

### git-flow-common (9.0K)
**Назначение:** Библиотека общих функций и констант  
**Как использовать:** Подключается автоматически другими скриптами через `source`  
**Функции:**
- 25+ вспомогательных функций
- Константы цветов для вывода
- Функции работы с ветками
- Управление состоянием операций
- Обработка конфликтов
- Валидация и парсинг данных

---

### git-flow-deliver (7.6K)
**Назначение:** Автоматизация доставки изменений  
**Как использовать:** `git flow deliver` (из feature ветки)  
**Функции:**
- Выбор количества коммитов для доставки
- Cherry-pick в stable ветку
- Squash коммитов
- Merge в целевое окружение (test/release_oe/release_pe)
- Обновление существующих PR
- Сохранение состояния при конфликтах

**Требования:** Должны быть в ветке формата `tasks/PARENT_JIRA/JIRA`

---

### git-flow-hotfix (6.0K)
**Назначение:** Создание и работа с hotfix ветками  
**Как использовать:** `git flow hotfix create` или `git flow hotfix push`  
**Функции:**
- Создание hotfix веток для PE/OE/IZ
- Cherry-pick коммитов в версионные ветки
- Валидация версий (формат XX.XX.XX.X)
- Автоматический push

**Требования:** Наличие версионных веток `versions/{type}/{version}`

---

### git-flow-continue (11K)
**Назначение:** Продолжение операций после конфликтов  
**Как использовать:** `git flow continue` (после разрешения конфликтов)  
**Функции:**
- Загрузка сохраненного состояния
- Продолжение cherry-pick операций
- Продолжение merge операций
- Автоматическое завершение оставшихся шагов
- Очистка состояния после успеха

**Поддерживаемые операции:**
- stable-cherry-pick
- merge-to-test
- merge-to-release_oe
- merge-to-release_pe
- hotfix-cherry-pick

---

### install.sh (3.4K)
**Назначение:** Скрипт установки плагина  
**Как использовать:** `./install.sh`  
**Функции:**
- Копирование файлов в ~/.local/bin
- Установка прав доступа (executable)
- Добавление в PATH (опционально)
- Проверка корректности установки

## Файлы состояния (создаются автоматически)

### .git/git-flow-state
**Создается:** Автоматически при конфликтах  
**Удаляется:** Автоматически после успешного завершения  
**Назначение:** Хранение состояния прерванных операций  
**Формат:**
```bash
OPERATION=<тип операции>
ORIGINAL_BRANCH=<исходная ветка>
PARENT_JIRA=<родительская JIRA>
JIRA=<JIRA задачи>
TARGET_ENV=<целевое окружение>
COMMITS=<список коммитов>
```

**Важно:** Не редактировать вручную!
