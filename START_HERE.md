## 🎯 Типичный сценарий работы

```bash
# 1. Создаете feature ветку (через меню или вручную)
git checkout -b tasks/PROJ-123/TASK-456 test

# 2. Разрабатываете и коммитите
git add .
git commit -m "Реализация функциональности"

# 3. Доставляете изменения
git flow deliver
# Выбираете количество коммитов: 1
# Выбираете окружение: test
# Соглашаетесь на squash: Y

# 4. Создаете PR из tasks/PROJ-123/test_TASK-456 в test

# 5. Готово! 🎉
```

## ❓ Часто задаваемые вопросы

### Как установить?
```bash
./install.sh
```

### Команда не найдена?
Проверьте PATH:
```bash
echo $PATH | grep ".local/bin"
```

Если пусто, добавьте:
```bash
export PATH="$HOME/.local/bin:$PATH"
```

### Что делать при конфликте?
```bash
# 1. Разрешите конфликт
vim <файл>

# 2. Добавьте файл
git add <файл>

# 3. Продолжите
git flow continue
```

Читайте **README.md**
