## ✨ Возможности

### 🎯 Основные функции

- **Интерактивное меню** - удобная навигация по всем функциям
- **Автоматическая доставка изменений** - от feature ветки до PR одной командой
- **Управление HotFix** - быстрое создание и доставка исправлений в версионные ветки
- **Умная работа с коммитами** - выбор конкретных коммитов, исключение merge-коммитов
- **Продолжение после конфликтов** - сохранение состояния и возможность продолжить с места остановки
- **Обновление существующих PR** - добавление новых изменений в существующие Pull Request
- **Анализ состояния** - полная информация о текущей ветке и связанных с ней ветках

### 🚀 Улучшения по сравнению с версией 1.0

1. **Выбор коммитов для доставки**
   - Интерактивный выбор: по номерам, диапазону или все сразу
   - Автоматическое исключение merge-коммитов
   - Просмотр истории перед выбором

2. **Обновление PR без пересоздания**
   - Автоматическое пересоздание merge-ветки
   - Force push для обновления PR
   - Сохранение истории обсуждений в PR

3. **Продолжение после конфликтов**
   - Сохранение состояния при конфликтах
   - Команда `--continue` для продолжения
   - Поддержка многоэтапного разрешения конфликтов

4. **Поддержка всех веток доставки**
   - test (по умолчанию)
   - release_oe
   - release_pe

5. **HotFix механизм**
   - Работа с версионными ветками
   - Cherry-pick из любой ветки
   - Автоматическое создание PR

## 📦 Установка

### Автоматическая установка

```bash
# Клонируйте репозиторий или скачайте файлы
git clone <repository-url>
cd git-flow-helper

# Запустите установщик
./install.sh
```

### Ручная установка

```bash
# Скопируйте скрипт в директорию с исполняемыми файлами
cp git-flow-helper ~/.local/bin/
chmod +x ~/.local/bin/git-flow-helper

# Добавьте в PATH (если еще не добавлено)
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

# Опционально: создайте git алиасы
git config --global alias.flow '!git-flow-helper'
git config --global alias.deliver '!git-flow-helper deliver'
git config --global alias.hotfix '!git-flow-helper hotfix'
```

## 📚 Основные команды

### `git-flow-helper` (интерактивное меню)

Запускает интерактивное меню с доступными действиями в зависимости от текущей ветки.

**Доступные действия в feature ветке:**
- Доставить изменения
- Обновить существующий PR

**Общие действия:**
- Создать новую feature ветку
- Создать hotfix
- Анализ текущего состояния
- Очистка влитых веток

### `git-flow-helper deliver`

Автоматически доставляет изменения из feature ветки:
1. Выбор коммитов для доставки
2. Cherry-pick в stable ветку
3. Опциональный squash коммитов
4. Создание merge ветки
5. Push для создания PR

### `git-flow-helper hotfix`

Создает hotfix для версионной ветки:
1. Выбор версионной ветки (PE/OE/IZ)
2. Выбор конкретной версии
3. Выбор коммитов из test/release_oe/release_pe
4. Cherry-pick в hotfix ветку
5. Push для создания PR

### `git-flow-helper continue`

Продолжает процесс доставки после разрешения конфликтов:
- Восстанавливает сохраненное состояние
- Продолжает с места остановки
- Поддерживает многоэтапное разрешение

### `git-flow-helper status`

Анализирует текущее состояние:
- Тип текущей ветки
- Существующие связанные ветки
- Открытые PR
- Незафиксированные изменения
- Сохраненное состояние доставки

## 🔄 GitFlow процесс

### Структура веток

```
master          - ветка стабилизации
test            - ветка разработки
release_oe      - опытная эксплуатация
release_pe      - промышленная эксплуатация
```

### Feature разработка

```
1. Создание feature ветки:
   tasks/PARENT_JIRA/JIRA (от test)
   
2. Стабилизация:
   tasks/PARENT_JIRA/stable_JIRA (от master)
   
3. Merge ветки:
   tasks/PARENT_JIRA/test_JIRA
   tasks/PARENT_JIRA/release_oe_JIRA
   tasks/PARENT_JIRA/release_pe_JIRA
```

### HotFix процесс

```
1. Версионные ветки:
   versions/pe/XX.XX.XX.X
   versions/oe/XX.XX.XX.X
   versions/iz/XX.XX.XX.X
   
2. HotFix ветки:
   hotfixes/pe/JIRA
   hotfixes/oe/JIRA
   hotfixes/iz/JIRA
```

## 🔧 Работа с конфликтами

### При cherry-pick конфликте

```bash
# 1. Скрипт остановится и покажет инструкции
# 2. Разрешите конфликты вручную
# 3. Добавьте файлы в индекс
git add <файлы>

# 4. Продолжите доставку
git-flow-helper continue
```

### При merge конфликте

```bash
# 1. Скрипт остановится и покажет инструкции
# 2. Разрешите конфликты вручную
# 3. Добавьте файлы и закоммитьте
git add <файлы>
git commit

# 4. Продолжите доставку
git-flow-helper continue
```

## 🐛 Решение проблем

### Проблема: Команда git-flow-helper не найдена

**Решение:**
```bash
# Проверьте PATH
echo $PATH

# Добавьте директорию в PATH
export PATH="$HOME/.local/bin:$PATH"

# Сохраните в .bashrc/.zshrc
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

### Проблема: Permission denied при запуске

**Решение:**
```bash
chmod +x ~/.local/bin/git-flow-helper
```

### Проблема: Скрипт завис на незавершенном действии

**Решение:**
```bash
# Проверьте состояние
git-flow-helper status

# Очистите состояние если нужно начать заново
rm .git-flow-helper-state

# Или продолжите если хотите завершить
git-flow-helper continue
```

### Проблема: Конфликты при cherry-pick

**Решение:**
1. Разрешите конфликты в файлах
2. Добавьте разрешенные файлы: `git add <файлы>`
3. Продолжите: `git-flow-helper continue`

### Проблема: Force push перезаписывает изменения

**Решение:**
- Force push используется только для обновления PR
- Всегда проверяйте что никто не работает в той же ветке
- Используйте `--force-with-lease` для безопасности

## 📝 Конфигурация

Скрипт сохраняет конфигурацию в `~/.git-flow-helper.conf` (будет добавлено в будущих версиях).

Временное состояние сохраняется в `.git-flow-helper-state` в корне репозитория.
