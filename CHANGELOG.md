# История изменений

## [1.0] - 2025-08-17

### Функции v1.0

- Базовая автоматизация delivery
- Работа только с test веткой
- Cherry-pick только последнего коммита
- Создание stable и test веток
- Push в удаленный репозиторий

### Ограничения v1.0

- ❌ Невозможно выбрать количество коммитов
- ❌ Merge коммиты включались в cherry-pick
- ❌ Отсутствие обработки конфликтов
- ❌ Нет поддержки hotfix
- ❌ Нет возможности обновить PR
- ❌ Завершение при любой ошибке

## [2.0] - 2025-10-17

### ✨ Новые возможности

- **Интерактивное меню** - красивое меню с автоопределением доступных команд
- **Выбор количества коммитов** - можно выбрать N коммитов или все (all)
- **Фильтрация merge-коммитов** - автоматическое исключение merge коммитов при cherry-pick
- **Обновление PR** - возможность пересоздать merge ветку для обновления PR
- **Продолжение после конфликтов** - сохранение состояния и продолжение операций
- **Поддержка hotfix** - создание и работа с hotfix ветками для версионных релизов
- **Squash коммитов** - автоматическое объединение коммитов в stable ветке
- **Выбор окружения** - доставка в test, release_oe или release_pe

### 🔧 Улучшения

- Модульная архитектура с общей библиотекой функций
- Улучшенная обработка ошибок
- Информативные сообщения на каждом шаге
- Валидация всех входных данных
- Безопасный push с force-with-lease
- Автоматическое обновление веток из remote

### 📚 Документация

- Полная документация (README.md)
- Быстрый старт (QUICKSTART.md)
- Подробные примеры (EXAMPLES.md)
- Описание архитектуры (ARCHITECTURE.md)
- Обзор проекта (PROJECT_OVERVIEW.md)

### 🐛 Исправлено

- Исправлена проблема с доставкой только последнего коммита
- Исправлено завершение при конфликтах
- Исправлено отсутствие возможности обновить PR

## Планы на будущее

- Автоматическое создание PR через gh CLI
- Поддержка кастомных конфигураций GitFlow
- Интеграция с Jira API
- Статистика и аналитика использования
- Pre/post операционные hooks
- Параллельная доставка в несколько окружений
- Rollback функциональность
- Улучшенное интерактивное меню с поиском
- Поддержка множественного cherry-pick для hotfix
